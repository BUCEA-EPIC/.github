## 关于我们

光启Ray-space工作室的历史最早可以追溯到 2013 年，是在北京建筑大学工程实践创新中心指导下成立的多学科交叉学术科技团队。

我们面向机器人、机械、电控与计算机视觉开展工程实践，在真实项目、长期训练与赛事协作中，将机械结构、电子控制、嵌入式系统与感知算法整合为能够落地的作品。我们希望搭建一个开放、协作的技术交流平台，让成员从基础学习走向项目推进，从单点技能走向系统协同。

## 技术方向

- **机器人系统**：围绕移动、感知、决策与执行构建完整机器人系统
- **机械结构**：开展三维建模、结构设计、装配与工程实现
- **电控与驱动**：实践嵌入式开发、PCB 设计、运动控制与系统联调
- **计算机视觉**：探索环境感知、目标识别、SLAM 与智能决策

## 代表项目

### [2025 工创大赛智能救援机器人](https://github.com/BUCEA-EPIC/intelligent-rescue-2025)

以 NVIDIA Jetson Orin NX Super 负责环境感知与智能决策，以 STM32 作为运动控制下位机，面向复杂未知环境实现自主救援；项目算法已开源。

更多作品请访问[项目与机器人](https://rayspace.org/projects)。
